**ElegantStyle** is a landing-page fashion store designed as a modern boutique for bold, trend-focused customers.  
It features a clean layout, strong visuals, and minimal distractions.  
The website is fully in English and geo-targeted to the United States.

## 🔧 Technologies

- HTML5  
- CSS3  
- JavaScript  
- Responsive layout (mobile-first approach)  
- Semantic HTML structure  
- Cross-browser compatibility
